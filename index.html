WonderScope Publisher

WonderScope Publisher is a private command-line tool that uploads short science and trivia videos to the operator's own YouTube channels, such as WonderScope (@WonderScope_jp). It uses the YouTube Data API v3 (YouTube API Services).

What it does

  1. The operator reviews each finished video and approves it. When approving, the operator chooses the title, the description, the privacy setting (public, unlisted or private), whether the video is made for kids, and the publication time. Before approval, the tool shows the exact information it will send to YouTube.
  2. Ahead of the publication time (currently about 24 hours before), the tool uploads the approved video. For a public video, it schedules publication for the chosen time.
  3. The tool checks that the upload finished and that the video was published. It keeps checking published videos so that its records match YouTube, and it notifies the operator of the results.

Google user data it requests

  • youtube.upload: to upload the approved videos and set their thumbnails.
  • youtube.readonly: to confirm which channel the authorized account belongs to, and to check the status of the videos the tool manages.

The tool does not read viewing history, comments, subscribers or analytics. See the Privacy Policy for details.

Who can use it

Only the operator. The tool runs on the operator's own computer. There is no sign-up, and the tool is not distributed.

WonderScope Publisher

WonderScope Publisher は、科学や雑学の短い動画を、運営者自身の YouTube チャンネル（WonderScope（@WonderScope_jp）など）にアップロードする、個人用のコマンドライン ツールです。YouTube Data API v3（YouTube API サービス）を使います。

できること

  1. 運営者が、できあがった動画を 1 本ずつ確かめて承認します。承認のときに、タイトル、説明文、公開設定（公開・限定公開・非公開）、子ども向けかどうか、公開日時を決めます。承認の前に、本ツールは YouTube に送る内容をそのまま表示します。
  2. 公開日時より前（現在は約 24 時間前）に、承認された動画をアップロードします。公開の動画は、選んだ日時に公開されるよう予約します。
  3. アップロードが終わったか、公開されたかを確かめます。公開済みの動画もその後に確かめて記録を YouTube と合わせ、結果を運営者に知らせます。

求める Google のユーザーデータ

  • youtube.upload: 承認された動画をアップロードし、サムネイルを設定するため。
  • youtube.readonly: 許可したアカウントのチャンネルを確かめ、本ツールが扱う動画の状態を確かめるため。

視聴履歴、コメント、登録者、アナリティクスは読みません。詳しくはプライバシーポリシーをご覧ください。

使う人

運営者だけです。本ツールは運営者のコンピューターで動きます。登録の手続きはなく、配布もしていません。
